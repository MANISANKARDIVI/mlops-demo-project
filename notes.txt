What is Machine Learning?
Machine learning is a process of training a machine or computer with huge amount of data so that it identifies the patterns and predicts the output.

what is a model?
A model is basically output of the machine learning process after it has been trained with data, model is a mathematically function that maps input data to output predictions.

what is dataset?
A dataset is usually a data that has the information of different features  of the entities it represents, and it is used to train and evaluate machine learning models.

what is feature?
A feature is an individual measurable property or characteristic of a phenomenon being observed, and it is used as input to train machine learning models.

what is MLOps?
MLOps, short for Machine Learning Operations, is a set of practices that aims to deploy and maintain machine learning models in production reliably and efficiently.


Machine Learning Lifecycle?
The machine learning lifecycle refers to the series of stages that a machine learning project goes through, from problem definition and data collection to model deployment and monitoring. The typical stages include:
- Problem Definition
- Data Collection
- Data Preparation / Data Cleaning
- Feature Engineering
- Model Selection
- Model Training
- Model Evaluation
- Hyperparameter Tuning
- Model Deployment
- Monitoring and Maintenance


what is DVC?
DVC, short for Data Version Control, is an open-source version control system for machine learning projects. It helps manage datasets, machine learning models, and experiments, enabling reproducibility and collaboration in ML workflows.

Difference between Git and DVC?
Git is version control system for source code,
DVC is version control system for datasets and machine learning models.

why Git is not enough for machine learning projects?
Git is primarily designed for versioning source code, which is usually small in size. Machine learning projects involve large datasets and models that are not efficiently handled by Git. DVC complements Git by providing version control for these large files, ensuring reproducibility and efficient collaboration.


how to install DVC?
You can install DVC using pip, the Python package manager, with the following command:

$ uv venv
$ source .venv/bin/activate
$ uv pip install -r requirements.txt

Then choose a dataset file, and add it to DVC using the following command:

$ dvc add <dataset_filename>

After adding the dataset to DVC, a corresponding `.dvc` file will be created.

How to store data in s3?
To store data in Amazon S3 using DVC, you need to configure an S3 remote. Here are the steps:

1. Configure the S3 remote:
$ dvc remote add -d myremote s3://mybucket/path

$ dvc remote modify myremote access_key_id <your_access_key_id>
$ dvc remote modify myremote secret_access_key <your_secret_access_key>

IMP: we need to add dvc_s3 package to enable S3 support in DVC.
$ pip install dvc-s3

2. git add & git commit & git push the .dvc metadata files to the Git repository.
$ git add . &&git commit -m "Add DVC metadata files" &&git push


3. Push the data to the S3 remote:
$ dvc push


4. Pull the data from the S3 remote:
$ dvc pull


What is the use of Mlflow?
Mlflow is an open-source platform for managing the end-to-end machine learning lifecycle. It provides tools for experiment tracking, model management, and deployment, helping data scientists and ML engineers to organize and reproduce their work efficiently.

for local development, you can set the MLflow tracking URI to your local server:
# Default: SQLite database (mlflow.db in current directory port:5000)
$ mlflow server

# PostgreSQL: connect to an existing PostgreSQL database for production use
$ mlflow server --backend-store-uri postgresql://username:password@host:port/database
